# Intelligent Attendance Monitoring System

## Overview
C++ application to manage student attendance, calculate percentage, classify academic risk, and generate a defaulter list.

## Features
- Add student records
- Calculate attendance %
- Risk classification (Safe / Warning / High Risk)
- Search by ID
- Sorted defaulter list

## Data Structures Used
- Array
- Struct
- Linear Search
- Bubble Sort
